# Inżynieria finansowa 1: Projekt II

## Opis projektu

Głównym celem projektu jest implementacja jawnej metody różnic skończonych (explicit finite difference method) oraz wykorzystanie jej do wyceny i analizy opcji barierowych knock-out opartych o indeks WIG20. Rozważane są europejskie i amerykańskie opcje kupna i sprzedaży, przy uwzględnieniu niepewnej zmienności z zadanego przedziału, a także wpływu bariery, ceny wykonania, dywidendy dyskretnej oraz czasu do zapadalności na wartość instrumentów i momenty wcześniejszego wykonania.
